# One Word From Grandma

One word (2 characters): the word grandma would text about AI. She reads "AI" as "Al" — a man who answers questions.

> Al

`main.py` (Python 3.13, stdlib only) writes that word to `/output/entry.txt`. Deterministic: the same text on every run.
